## 背景

组合甘特图用于汇报截图时，当前会同时展示全部项目。Human Owner 需要只展示一个指定项目（例如 B2B Intelligence 360（二期））及其完整子树，排除 Marketing AI、BRD → PRD AI 提效等其他顶级项目；未选项目不能压缩成线或留下空白行。

此能力是**纯浏览器展示筛选**：它不能改变任何项目、步骤、日期、层级、审计或后端数据，也不能改变 MCP / Skill 的能力或调用合同。

## scope_in

1. 在组合甘特图左侧表头 `项目 / 业务预期` 的标题旁增加紧凑入口，默认文案为 `显示项目 n/n`；分母和分子均为当前组合中可见的顶级项目数，不把子项目重复计数。
2. 点击入口打开“汇报筛选”浮层/菜单：
   - 仅列出顶级项目，每项为复选框；不把子项目列成可单独打散的独立选择项。
   - 提供 `全部显示`、`取消`、`应用`；`取消`不得改变当前已生效筛选。
   - `应用`后，选中集合写入当前浏览器的 `localStorage` 展示偏好，键必须按组合 ID 隔离；不得发送写 API 或 MCP 请求。
3. 已应用筛选后：
   - 仅渲染所选顶级项目及其全部后代的项目行、步骤条、依赖说明与 TBD 工作包分组；未选项目不留空白行，也不折叠为占位线。
   - 时间表头、当前日期线、日/周/月切换、手动日期范围和步骤真实 `colStart` / `colEnd` 均保持原语义，不因筛选自动重排、自动缩放或改写。
   - 顶部明确显示已生效状态，例如 `汇报筛选：仅显示 1 / 3 个顶级项目`，并提供可见的 `全部显示` 恢复入口。
4. 点击任一 `全部显示` 后立即恢复全部顶级项目及完整子树，并清除该组合的本地筛选偏好；恢复过程不得调用写 API/MCP。
5. 刷新页面后，同一组合的已应用筛选应恢复；切换至另一项目组合不得串用筛选集合。
6. 添加必要的前端自动化/可重复验证，以覆盖顶级父子筛选、TBD 筛选、取消/应用/全部显示、刷新恢复，以及无写请求的保护。

## 验收标准

1. **入口与计数**：有 3 个顶级项目及任意子项目时，甘特表头可见 `显示项目 3/3`；子项目不能影响计数。入口可用键盘聚焦、打开及关闭。
2. **树级选择**：浮层仅列出顶级项目。仅勾选一个顶级项目并应用后，页面只显示该项目与所有后代；同一项目分支的步骤条、依赖说明和 TBD 分组仍完整可见。
3. **无空白占位**：取消勾选的顶级项目及所有后代不产生 `.gantt-row`、时间轴轨道高度或未排期分组；截图区域不能保留折叠线或空白行。
4. **安全恢复**：`取消`保留应用前视图；`全部显示`恢复所有顶级项目，表头回到 `显示项目 3/3`，且恢复前后项目/步骤数据未变化。
5. **本地隔离**：应用筛选后刷新恢复；切换组合后不复用其它组合的筛选。浏览器 Network/测试证据表明筛选、应用、取消和恢复均不发出 `POST`、`PUT`、`PATCH`、`DELETE` 请求，也不调用 MCP。
6. **时间线不失真**：对筛选前后同一可见步骤，其 `colStart`、`colEnd`、实际渲染日期位置、当前日期线、手动日期范围、日/周/月表头文本均保持一致；筛选不得自动改变区间。
7. **非回归**：`npm run lint`、`npm test`、`npm run test:e2e`、`npm run test:scheduled`、`npm run skill:build`、`node scripts/validate-skill-consistency.mjs`、`npm run build`、`git diff --check` 全部通过；MCP `tools/list` 仍严格为 31 个工具。
8. **范围审计**：`git diff --name-only` 仅包含允许修改文件；无 `wrangler deploy`、无 Cloudflare secret/D1/R2/DNS/Git remote 操作；无 token、密码或真实业务数据写入源码、测试或报告。
