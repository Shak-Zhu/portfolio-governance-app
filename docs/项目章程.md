# 项目章程｜Shak 项目组合治理系统

## 项目目标

交付“Shak 项目组合治理系统”：用户维护项目主数据，系统自动生成可汇报的组合甘特图；不再以 Cooper 为生产数据源。

## 已确认的产品边界

- 生产入口：`https://pmo.pmoforms.com`
- 前端与 API：Cloudflare Worker
- 主数据：Cloudflare D1
- 后续备份：Cloudflare R2；当前账户尚未开通 R2。
- 后续自动化：认证后的原生远程 MCP 与中文使用说明。
- 不包含成本、预算、资源/工时管理、复杂 WBS 或 Cooper 自动同步。

## 角色

| 角色 | 人员 / 系统 | 职责 |
|---|---|---|
| Human Owner | Shak | 业务方向、重大决策、最终验收 |
| PM / QC | Codex | 范围、工作包、质量与上线门禁 |
| Coder | Cursor | 按工作包实现并提交验证证据 |

## 分阶段交付

1. WP-002A：Web App 与 D1 核心数据层。
2. WP-002B：R2 备份与恢复演练（依赖 R2 开通）。
3. WP-003：认证 MCP、中文使用说明与 Agent 验证。
4. WP-004：PM/QC、上线与 Human Owner 验收。
