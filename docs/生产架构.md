# 生产架构｜v1.2（WP-008）

```text
Browser Web App
  └─ Cloudflare Worker (静态前端 + REST API + 网页登录 + 原生认证 /mcp + 定时备份)
       ├─ D1: `pmo-governance-prod`（binding: `DB`）
       └─ R2: `pmo-governance-backups-prod`（binding: `BACKUPS`）
```

## 核心规则

- `steps` 是每根甘特条的唯一数据来源；每条包含名称、开始、结束和状态。
- `projects.parent_id` 表示父子层级；首页 KPI 仅统计顶级项目（`parent_id IS NULL`）。
- 项目关联资料采用一对多数据模型，保存显示标题与 `http(s)` URL；资料与项目同生命周期管理。
- Stage 支持新增与编辑；已被项目使用的 Stage 不可删除或改名。
- 仅顶级项目可以归档；归档前必须验证所有后代项目均已完成。
- 所有网页与 MCP 写操作写入 `audit_events`，记录 actor、时间、对象、变更前后摘要。

## 鉴权边界（WP-006）

- **网页**：单用户邮箱+密码登录；Session 由 Worker Secret `SHAK_PMO_SESSION_SECRET` HMAC-SHA256 签名；
  Cookie `HttpOnly; Secure; SameSite=Strict; Path=/`，8 小时有效；登出立即失效。
  凭据来源：`SHAK_PMO_WEB_LOGIN_EMAIL` / `SHAK_PMO_WEB_LOGIN_PASSWORD`，由 Codex 通过 `wrangler secret put` 注入。
- **`/mcp`**：仅校验 `Authorization: Bearer <token>`；Token 与 Worker Secret `SHAK_PMO_MCP_TOKEN` 时序安全比较；
  缺失/错误 → JSON 401；正确 → 官方 `agents/mcp` 的 `createMcpHandler`。
- `/mcp` 与网页登录完全独立：无 Cookie 的 MCP Client 带正确 Bearer 即可成功；不被登录拦截。
- **不存在 OAuth、scope、动态注册、KV token/grant、Access OAuth、`.well-known/oauth-*` 任何机制**。
- **所有 MCP 写工具**的审计 actor 固定为 `mcp:shak-pmo-owner`，由服务端注入，客户端不可覆盖。

## 数据安全边界

- D1 为主数据源；Worker 重部署不得删除或重建已有业务数据。
- schema 变更只能用可重复执行的 migration。
- **R2 逻辑备份（WP-008）**：
  - Worker `scheduled()` 每天 UTC 03:00 自动触发一次逻辑备份，由 `wrangler.toml` cron 配置。
  - 备份覆盖 6 张业务表：`portfolios`、`projects`、`stages`、`steps`、`project_links`、`audit_events`。
  - 备份格式为 JSON，含 `schemaVersion`、`createdAt`、逐表行数摘要、逐表 SHA-256、整体内容 SHA-256。
  - R2 key 格式：`backups/YYYY-MM-DD/<timestamp>.json`。
  - 每次成功后保留最近 30 份，超出后自动删除最旧备份；备份/清理失败在控制台明确记录错误。
  - **恢复演练**：网页端提供备份列表、手动备份和恢复演练入口，仅恢复到隔离/测试 D1（如 `TEST_DB`），**严禁覆盖生产 D1**。
  - 恢复演练验证：JSON 结构、`contentSha256`、表存在、逐表行数、逐表 SHA-256。
  - 备份 API 路由（`GET/POST /api/backups`、`POST /api/backups/restore`）受网页登录保护，未登录返回 401。
  - 不向 MCP 暴露任意 R2、任意 SQL 或恢复工具。
- MCP 写操作不得匿名开放；鉴权由 WP-006 单用户 Bearer Token 提供。
- MCP 使用 Streamable HTTP；唯一鉴权是 Bearer Token；actor 固定为 `mcp:shak-pmo-owner`。
- MCP 只调用与网页 REST API 相同的治理服务/规则；不得提供任意 SQL、任意 HTTP 转发或绕过父子归档、Stage、URL、日期校验的工具。
- Agent Skill 源码进入 Git；Codex 发布后将最终 40 位 commit 写入 `SHAK_PMO_SKILL_SOURCE_COMMIT`，网页 `/api/agent/install` 只使用该 commit 下的精确 GitHub raw Bundle URL，并按 manifest 逐文件 SHA-256 校验后安装。该接口在登录会话内动态返回带真实 Token 的复制文案，并设置 `Cache-Control: no-store`；Token 永不出现在静态资产、Git、Skill、manifest、日志或报告。
