## L3 不通过项

### 1. Scope violation：Skill manifest 被改动

`agent-skills/shak-project-portfolio-governance/manifest.json` 的 `generatedAt` 从 `2026-07-30T16:35:51.645Z` 改为 `2026-08-19T16:07:42.336Z`。即使是构建副作用，也违反 WP-011 的明确禁止项：`agent-skills/**` 不得修改。

**修复要求**：仅恢复该文件至 WP-011 开始前的 Git 基线；不得改 Bundle 任何其它文件、hash、版本或发布指针。

### 2. GET 读取失败时可能用旧组合项目树过滤当前甘特

`ensureProjectsLoaded()` 请求失败后只记录错误，没有清空/隔离 `state.projects`。若用户刚从组合 A 切到组合 B，B 的项目读取短暂失败，`applyReportFilter()` 仍可能用 A 的父子关系计算 B 的可见集合，从而显示错误分支或空白截图。

**修复要求**：

- 读取失败必须 fail-safe：当前组合的汇报筛选不可用，直接渲染未筛选的 `data.rows` 与 `data.unscheduled`；
- 清除当前组合的临时筛选状态或明确禁用入口并显示“项目树读取失败，已显示全部项目”；不得使用任何旧组合的 `state.projects`；
- 成功读取后才允许按该组合的项目树应用筛选。

### 3. 本地旧/非法筛选值未校验，且可应用零项目

当前实现将 localStorage 中任意字符串直接放入 `Set`，并以 `selected.size` 作为分子。项目被归档、删除或调整为子项目后，页面可能显示 `显示项目 1/3`，但实际一行都没有。用户还可取消所有勾选后应用，导致无项目空白视图。

**修复要求**：

- 每次应用/恢复筛选时，用当前组合的有效顶级项目 ID 清理 selection；计数以清理后的有效顶级集合计算；
- 若本地值经清理后为空，删除该组合 localStorage 键并恢复“全部显示”；不得显示空项目甘特；
- 浮层中至少保留一个顶级项目时才允许“应用”，或在用户取消最后一项时自动恢复全选；按钮/提示须可理解；
- 增加覆盖“过期 ID”“跨组合读取失败”“零选项”的实际实现测试。

## 测试证据缺口

**修复要求**：测试必须验证生产实现本身，或将共享的筛选纯函数抽取为由页面和测试共同引用的唯一实现。不得保留两份可漂移的算法副本。
